# Model Graph Assets

Netron screenshot steps:
1) Install Netron (https://netron.app) and open it.
2) File -> Open -> select `assets/model.onnx`.
3) Capture the graph screenshot for your report.

No Netron option:
- Open `assets/model_graph.txt` and use it as a lightweight structural screenshot alternative.

MoE routing diagram:
- Open `assets/moe_routing.drawio` in draw.io (diagrams.net) and export to PNG if needed.
